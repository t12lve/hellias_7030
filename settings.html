Setup OBS / Streamlabs / StreamElements

  • Ajouter une Browser Source pointant vers overlay.html (fichier local).
  • Dimensions = taille choisie (S/M/L). Custom CSS si besoin : body { background-color: rgba(0,0,0,0); }
  • Ne pas activer de fond de couleur sur la source — seul le widget a un fond.
  • Cocher « Shutdown source when not visible » optionnel ; garder « Refresh browser when scene becomes active » pour resync.
  • Ouvrir cette page settings.html dans un dock navigateur OBS pour ajuster en live.
